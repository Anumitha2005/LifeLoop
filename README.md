# LifeLoop - Everyday Life Organizer Website

# About the Project
LifeLoop is a personal productivity web application designed to help users organize and manage their everyday activities in one place.

# Features

 * Personal productivity dashboard
 * Add and delete daily tasks
 * Mark tasks as completed
 * Task categories
 * Filter pending and completed tasks
 * Task summary dashboard
 * Browser-based data storage using LocalStorage

 # Technologies Used

  * HTML
  * CSS
  * JavaScript
  * LocalStorage

 #  Project Structure

  * index.html - Main dashboard
  * style.css - Website design and styling
  * script.js - Task management functionality

# How to Run

1. Download or clone this repository
2. Open the project folder
3. Open index.html in a web browser.
